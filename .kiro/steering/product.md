# Product Overview

REFUGE Restrooms is a web application providing safe restroom access information for transgender, intersex, and gender nonconforming individuals.

## Purpose

- Community-driven database of gender-neutral and safe restrooms
- Successor to the defunct Safe2Pee website
- Free resource for trans* and queer individuals

## Key Features

- Searchable database of restroom locations with accessibility information
- Geolocation-based search for nearby restrooms
- REST API for third-party integrations
- Multi-language support (English, Spanish, Filipino, French, Hindi, Italian, Polish, Portuguese-BR)
- Admin panel for content moderation
- Mobile apps (Android, iOS) and SMS integration available

## User Types

- Public users: Search and submit restroom information
- Admin users: Moderate submissions and manage content
- API consumers: Third-party apps and services

## Social Mission

This is an open-source community project focused on safety and accessibility for LGBTQ+ individuals.
